rodney - Chrome automation from the command line

Browser lifecycle:
  rodney start [--show] [--insecure|-k] [--incognito]
                                  Launch Chrome (--show visible, --incognito uses a
                                  throwaway profile deleted on stop)
  rodney connect <host:port>      Connect to existing Chrome on remote debug port
  rodney stop                     Shut down Chrome
  rodney status                   Show browser status

Navigation:
  rodney open <url> [--reuse]     Navigate to URL (--reuse: switch to an
                                  existing page at that URL instead of
                                  navigating the active page away)
  rodney back                     Go back in history
  rodney forward                  Go forward in history
  rodney reload [--hard]          Reload page (--hard bypasses cache)
  rodney clear-cache              Clear the browser cache

Page info:
  rodney url                      Print current URL
  rodney title                    Print page title
  rodney html [selector]          Print HTML (page or element)
  rodney text <selector>          Print text content of element
  rodney attr <selector> <name>   Print attribute value
  rodney pdf [file]               Save page as PDF
  rodney resource <url> [file|-]  Print cached body of a loaded resource
                                  (no new request; substring URL match)
  rodney history                  Print navigation history (* marks current)

Interaction:
  rodney js <expression>          Evaluate JavaScript expression
  rodney click <selector>         Click an element
  rodney input <selector> <text>  Type text into an input field
                                    (sets .value directly, no key events)
  rodney type <text>              Type text as real keyboard input into the
                                    focused element (fires key/input events)
  rodney press <key> [key ...]    Press keys as real keyboard events
                                    (enter, tab, escape, ctrl+a, shift+tab ...)
  rodney clear <selector>         Clear an input field
  rodney file <selector> <path|-> Set file on a file input (- for stdin)
  rodney download <sel> [file|-]  Download href/src target (- for stdout)
  rodney select <selector> <val>  Select dropdown option by value
  rodney submit <selector>        Submit a form
  rodney hover <selector>         Hover over an element
  rodney focus <selector>         Focus an element
  rodney scroll <x> <y> [--steps N]  Scroll page by pixels (negative y = up)
  rodney scroll-el <selector>     Scroll an element into view

Waiting:
  rodney wait <selector>          Wait for element to appear
  rodney wait --url <substring>   Wait until the URL contains a substring
  rodney waitnav                  Wait until the page navigates elsewhere
  rodney waitload                 Wait for page load
  rodney waitstable               Wait for DOM to stabilize
  rodney waitidle                 Wait for network idle
  rodney sleep <seconds>          Sleep for N seconds

Screenshots:
  rodney screenshot [-w N] [-h N] [--full] [file]  Take page screenshot
                                  (default: full page; -h limits to viewport)
  rodney screenshot-el <sel> [f]  Screenshot an element

Video recording:
  rodney start-video              Start recording video
  rodney stop-video [file]        Stop and save (.gif default, .mp4 needs ffmpeg)

Dialogs:
  rodney dialog [--dismiss] [--text MSG] [--json]
                                  Handle JS dialogs (alert/confirm/prompt).
                                  Foreground process — handles every dialog
                                  until Ctrl+C. Default accepts; --dismiss
                                  cancels; --text answers prompts. Arm it
                                  BEFORE triggering, an already-open dialog
                                  blocks all other commands.

Tabs:
  rodney pages [--json]          List all pages/tabs (--json: machine-readable,
                                  includes stable t:IDs and active flag)
  rodney page <index|t:id>        Switch to page by index or target ID
                                  (t:<id> is drift-proof for parallel sessions)
  rodney newpage [url]            Open a new page/tab
  rodney closepage [index|t:id]   Close a page/tab (t:<id> drift-proof)

Element checks:
  rodney exists <selector>        Check if element exists (exit 1 if not)
  rodney count <selector>         Count matching elements
  rodney visible <selector>       Check if element is visible (exit 1 if not)
  rodney assert <expr> [expected] [-m msg]  Assert JS expression (truthy or equality)

Cookies:
  rodney cookie-set <name> <val> [opts]  Set a cookie (defaults to current page)
  rodney cookie-get [name] [--json]      Get cookies (name for value, omit for all)
  rodney cookie-delete <name> [opts]     Delete cookies by name
  rodney cookie-clear [--domain <dom>]    Clear all cookies (or just one domain)

Emulation:
  rodney ua <user-agent>            Override browser user agent string
  rodney timezone <timezone-id>     Override timezone (e.g. "Asia/Tokyo")
  rodney locale <locale>            Override locale (e.g. "de-DE")
  rodney geo --lat N --lon N        Spoof geolocation coordinates
  rodney media [--type T] [--feature name=value ...]
                                    Emulate media type or features

Network interception:
  rodney mock <pattern> <response> [--status N] [--type MIME] [--method M]
                                    Serve a canned response for matching
                                    requests (persistent until Ctrl+C)
  rodney block <pattern> [--method M]
                                    Fail matching requests client-side
                                    (persistent until Ctrl+C)

Console:
  rodney console [--level L] [--json] [--browser] [--follow] [--clear]
                                    Show console output. Without a background
                                    collector: live stream (Ctrl+C to stop).
                                    With collector: print buffered messages.
                                    --level: log, info, warn, error, debug
                                    --json: JSON lines; --browser: also browser
                                    log entries; --follow: tail mode; --clear:
                                    print and empty the buffer
  rodney console-start             Start background console collector (captures
                                    logs between commands into console.jsonl)
  rodney console-stop              Stop collector and remove the buffer

Network requests:
  rodney requests [--json] [--follow] [--clear]
                                    Read network requests. Without a background
                                    collector: live stream (Ctrl+C). With
                                    collector: paired request/status lines
  rodney requests-start            Start background request collector
                                    (captures into requests.jsonl)
  rodney requests-stop             Stop collector and remove the buffer

Viewport & device emulation:
  rodney viewport <w> <h> [--clear]  Set viewport size (persisted in session)
  rodney device <name> [--landscape] [--clear] [--list]
                                    Emulate a device (viewport, DPR, touch,
                                    user agent) — e.g. iphone-x, pixel-2, ipad
  rodney headers [k=v ...] [--clear]
                                    Extra HTTP headers for every request
                                    (persisted in session; no args: list)

Accessibility:
  rodney ax-tree [--depth N] [--json]       Dump accessibility tree
  rodney ax-find [--name N] [--role R] [--json]  Find accessible nodes
  rodney ax-node <selector> [--json]        Show accessibility info for element

Selector convention:
  Commands taking <selector> accept CSS by default. Selectors starting
  with "//" or "(" are treated as XPath (e.g. rodney click "//button[@id='x']").

Options:
  --session <name>                Use a named session (~/.rodney-sessions/<name>/)
                                  — parallel sessions each own their state
  --local                         Use directory-scoped session (./.rodney/)
  --global                        Use global session (~/.rodney/)
  --version                       Print version and exit
  --help, -h, help                Show this help message

By default, commands auto-detect: if ./.rodney/state.json exists in the
current directory, the local session is used; otherwise the global session.
Use "rodney start --local" to create a directory-scoped session.

Environment:
  RODNEY_HOME                     Override data directory (default: ~/.rodney)

Exit codes:
  0  Success
  1  Check failed (exists, visible, assert, ax-find returned no match)
  2  Error (bad arguments, no browser, timeout, etc.)

Progressive help:
  rodney help <command>     Structured help for one command (description,
                           usage, flags, examples) — same as <command> --help
  rodney help --json       Full command registry as JSON (for scripts/agents)
