jodney - Chrome automation from the command line

Browser lifecycle:
  jodney start [--show] [--insecure | -k]  Launch Chrome (headless by default, --show for visible)
  jodney connect <host:port>      Connect to existing Chrome on remote debug port
  jodney stop                     Shut down Chrome
  jodney status                   Show browser status

Navigation:
  jodney open <url>               Navigate to URL
  jodney back                     Go back in history
  jodney forward                  Go forward in history
  jodney reload [--hard]          Reload page (--hard bypasses cache)
  jodney clear-cache              Clear the browser cache

Page info:
  jodney url                      Print current URL
  jodney title                    Print page title
  jodney html [selector]          Print HTML (page or element)
  jodney text <selector>          Print text content of element
  jodney attr <selector> <name>   Print attribute value
  jodney pdf [file]               Save page as PDF

Interaction:
  jodney js <expression>          Evaluate JavaScript expression
  jodney click <selector>         Click an element
  jodney input <selector> <text>  Type text into an input field
  jodney clear <selector>         Clear an input field
  jodney file <selector> <path|-> Set file on a file input (- for stdin)
  jodney download <sel> [file|-]  Download href/src target (- for stdout)
  jodney select <selector> <val>  Select dropdown option by value
  jodney submit <selector>        Submit a form
  jodney hover <selector>         Hover over an element
  jodney focus <selector>         Focus an element

Waiting:
  jodney wait <selector>          Wait for element to appear
  jodney waitload                 Wait for page load
  jodney waitstable               Wait for DOM to stabilize
  jodney waitidle                 Wait for network idle
  jodney sleep <seconds>          Sleep for N seconds

Screenshots:
  jodney screenshot [-w N] [-h N] [file]  Take page screenshot
  jodney screenshot-el <sel> [f]  Screenshot an element

Video recording:
  jodney start-video              Start recording video
  jodney stop-video [file]        Stop and save (.gif default, .mp4 needs ffmpeg)

Tabs:
  jodney pages                    List all pages/tabs
  jodney page <index>             Switch to page by index
  jodney newpage [url]            Open a new page/tab
  jodney closepage [index]        Close a page/tab

Element checks:
  jodney exists <selector>        Check if element exists (exit 1 if not)
  jodney count <selector>         Count matching elements
  jodney visible <selector>       Check if element is visible (exit 1 if not)
  jodney assert <expr> [expected] [-m msg]  Assert JS expression (truthy or equality)

Cookies:
  jodney cookie-set <name> <val> [opts]  Set a cookie (defaults to current page)
  jodney cookie-get [name] [--json]      Get cookies (name for value, omit for all)
  jodney cookie-delete <name> [opts]     Delete cookies by name
  jodney cookie-clear [--domain <dom>]    Clear all cookies (or just one domain)

Emulation:
  jodney ua <user-agent>            Override browser user agent string
  jodney timezone <timezone-id>     Override timezone (e.g. "Asia/Tokyo")
  jodney locale <locale>            Override locale (e.g. "de-DE")
  jodney geo --lat N --lon N        Spoof geolocation coordinates
  jodney media [--type T] [--feature name=value ...]
                                    Emulate media type or features

Network interception:
  jodney mock <pattern> <response> [--status N] [--type MIME] [--method M]
                                    Serve a canned response for matching
                                    requests (persistent until Ctrl+C)
  jodney block <pattern> [--method M]
                                    Fail matching requests client-side
                                    (persistent until Ctrl+C)

Accessibility:
  jodney ax-tree [--depth N] [--json]       Dump accessibility tree
  jodney ax-find [--name N] [--role R] [--json]  Find accessible nodes
  jodney ax-node <selector> [--json]        Show accessibility info for element

Options:
  --local                         Use directory-scoped session (./.jodney/)
  --global                        Use global session (~/.jodney/)
  --version                       Print version and exit
  --update                        Rebuild the binary from upstream source
  --help, -h, help                Show this help message

By default, commands auto-detect: if ./.jodney/state.json exists in the
current directory, the local session is used; otherwise the global session.
Use "jodney start --local" to create a directory-scoped session.

Environment:
  JODNEY_HOME                     Override data directory (default: ~/.jodney)

Exit codes:
  0  Success
  1  Check failed (exists, visible, assert, ax-find returned no match)
  2  Error (bad arguments, no browser, timeout, etc.)
